# Негативные кейсы

| Сценарий | Ожидаемое поведение |
|---|---|
| Повестка с уже существующим номером | `409 Conflict` |
| Неизвестный CitizenId | `404 Not Found` |
| Неизвестный AuthorityOfficeId | `404 Not Found` |
| DueAt раньше IssuedAt | `400 Bad Request` |
| Пустая причина | `400 Bad Request` |
| Изменение статуса несуществующей повестки | `404 Not Found` |
| Повтор текущего статуса | `409 Conflict` |
| Неизвестный канал уведомления | `400 Bad Request` |
| Пустой текст обращения | `400 Bad Request` |
| Поиск без результатов | `200 OK` и пустой массив |
| Недоступна БД | контейнер backend не проходит startup/health; ошибка видна в логах |
| Некорректный JSON | стандартный `400 Bad Request` ASP.NET Core |

## Безопасность данных

- в seed используются только синтетические данные;
- `.env` исключен из git;
- реальные идентификаторы граждан не должны попадать в dev/test;
- destination в ответах UI предполагается маскировать при развитии проекта.
