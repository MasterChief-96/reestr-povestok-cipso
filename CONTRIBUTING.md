# Contributing

## Общие правила

1. Создавайте ветку от `develop`.
2. Один PR — одна логическая задача.
3. Названия коммитов: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.
4. Для изменения модели данных обновляйте `docs/erd.md` и API-контракты.
5. Не коммитьте реальные персональные данные, пароли и `.env`.

## Definition of Done

- код собирается;
- основные позитивные и негативные кейсы обработаны;
- Swagger/контракты актуальны;
- документация обновлена;
- PR прошел review.
