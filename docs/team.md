# Роли команды

Заполните ФИО после формирования команды.

| Участник | Основные роли | Ответственность |
|---|---|---|
| Участник 1 | Backend, Database engineer | API, EF Core, модель БД |
| Участник 2 | Frontend, UX/UI | React, интерфейс, дизайн |
| Участник 3 | Team Lead, System Analyst, DevOps | декомпозиция, контракты, Docker, review |
| Участник 4 (опц.) | PM, Business Analyst | roadmap, документация, Kanban |
| Участник 5 (опц.) | QA/Backend | тесты, негативные кейсы, API |

При совмещении ролей в итоговой документации следует отдельно отметить ответственного за каждое направление.
