# Roadmap

## Реализовано

- [x] клиент-серверный реестр повесток военного учёта;
- [x] призывники и адреса регистрации;
- [x] военкоматы и сотрудники;
- [x] 25 синтетических повесток;
- [x] поиск, фильтры, пагинация;
- [x] карточка повестки со сроком явки;
- [x] история статусов и audit events;
- [x] обращения и метаданные документов;
- [x] mock-уведомления;
- [x] JWT и role-based authorization;
- [x] роли Секретарь / Комиссар / Призывник / Инженер автоматизации;
- [x] учётные записи пользователей;
- [x] заглушка входа MAX;

- [x] Docker Compose;
- [x] GitHub Actions.
